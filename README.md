# <img src="assets/palm-tree.gif" width="24"  /> Vacation Planner

A full-stack application for planning trips and discovering tourist attractions.

## Tech Stack

- **Backend:** NestJS, TypeScript
- **Database:** MongoDB, Mongoose
- **Frontend:** Angular *(planned)*

## Features

- Trip management (CRUD)
- Discovering tourist attractions using the OpenTripMap API *(planned)*

## Project Structure

- `backend/` — REST API
- `frontend/` — Angular application *(planned)*
